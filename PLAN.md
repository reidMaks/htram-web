# План реалізації: HTRAM Web Configurator & Monitor (UA)

Створення легкого автономного веб-застосунку для конфігурації та моніторингу датчика якості повітря **Honeywell Transmission Risk Air Monitor (HTRAM-V1-W)** через Web Bluetooth API.

Репозиторій: `/home/max/pet/htram-web`  
Аудиторія: Україна 🇺🇦 (інтерфейс виключно українською мовою)  
Донати: проста банка в Monobank (без сторонніх реєстрацій)

---

## 1. Головна цінність та функціональність

1. **Вимкнення набридливого зумера (Mute Buzzer):**
   - Перемикач звукового сповіщення без потреби випоювати зумер паяльником.
2. **Синхронізація годинника (Clock Sync):**
   - Встановлення поточного часу девайса в один клік з браузера смартфона чи комп'ютера.
3. **Моніторинг у реальному часі:**
   - CO2 (ppm) з кольоровою градацією (зелений < 800, жовтий 800–1000, червоний > 1000 ppm).
   - Температура (°C), відносна вологість (%), індикатор заряду батареї (4 поділки) та статус заряджання.
4. **Налаштування заліза:**
   - Зміна порогів CO2 для жовтої та червоної тривоги.
   - Автовимкнення підсвічування дисплея (завжди увімкнено / 1–30 хв).
   - Вибір одиниці температури на екрані (°C / °F).
5. **Простий донат:**
   - Стильна кнопка «На каву в Monobank 🐱» + дружнє контекстне вікно після успішного вимкнення зумера.

---

## 2. Технічний стек

- **Клієнт:** Сучасний Vanilla HTML5 + CSS3 (Glassmorphism / Dark Mode, адаптивний для смартфонів та ПК) + ES2022 JavaScript без жодних фреймворків чи білд-кроків.
- **Web Bluetooth:** пряма робота з GATT характеристиками (`fc247940-...`, write: `3d115840-...`, notify: `f833d6c0-...`) за протоколом із `ha-htram` з підрахунком CRC-16/0x8005.
- **Сервер / Деплой:** Dockerfile на базі `nginx:alpine` (~15 МБ) та `docker-compose.yml` для розгортання у вашому кластері.

## 4. План перевірки та тестування

1. **Перевірка бінарного протоколу:**
   - Порівняння згенерованих байтів пакетів (команда вимкнення звуку `CMD_SOUND_SET`, синхронізації часу `CMD_TIME_SYNC`, налаштувань порогів `CMD_SETTINGS_SET`) з еталонними даними в `custom_components/htram/protocol.py`.
2. **Перевірка локального веб-сервера:**
   - Запуск локального сервера / Docker-контейнера, перевірка коректності відображення інтерфейсу на мобільних і десктопних екранах.
3. **Ручне підключення до приладу:**
   - Відкриття у Chrome (локально через HTTPS або localhost).
   - Подвійний клік на кнопку HTRAM (блимання Bluetooth іконки).
   - Підключення, перевірка зчитування телеметрії та перемикання зумера.
