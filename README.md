# HTRAM Web Configurator & Monitor (UA) 🇺🇦

Автономний веб-застосунок для моніторингу та конфігурації датчика якості повітря **Honeywell Transmission Risk Air Monitor (HTRAM-V1-W)** через Web Bluetooth API.

Працює безпосередньо у браузері без хмарних серверів, без встановлення сторонніх додатків і без плати за акаунти розробників.

---

## 🎯 Головна цінність та функціональність

1. **Вимкнення зумера (Mute Buzzer) — Killer Feature**:
   - Можливість увімкнути або вимкнути звуковий сигнал тривоги без випоювання динаміка з плати.
2. **Синхронізація годинника (Clock Sync)**:
   - Встановлення поточного точного часу девайса з годинника браузера/телефону в один клік.
3. **Моніторинг показників у реальному часі**:
   - Рівень CO2 (ppm) з кольоровою шкалою (зелений < 800, жовтий 800–1000, червоний > 1000).
   - Температура повітря (°C).
   - Відносна вологість (%).
   - Рівень заряду батареї (4 поділки) та статус заряджання.
4. **Керування параметрами заліза**:
   - Налаштування порогів спрацьовування тривоги CO2 (Low / High ppm).
   - Налаштування таймера підсвічування екрана (автовимкнення через 1–30 хв або завжди увімкнений).
   - Перемикання одиниць температури на екрані приладу (°C / °F).
5. **Підтримка розробника**:
   - Кнопка «На каву в Monobank 🐱».
   - Контекстне повідомлення подяки після успішного вимкнення зумера.

## 🛠 Технологічний стек

- **Клієнтська частина**: чистий Vanilla HTML5, CSS3 (темна тема, glassmorphism, повна адаптивність під смартфони та ПК), ES2022 JavaScript без додаткових залежностей чи білд-етапів.
- **Bluetooth**: браузерний Web Bluetooth API (GATT service `fc247940-6e08-11e4-80fc-0002a5d5c51b`).
- **Розрахунок контрольних сум**: CRC-16 (поліном 0x8005).
- **Деплоймент**: `Dockerfile` на базі `nginx:alpine` (~15 МБ) та `docker-compose.yml` для власного кластера.

## 📡 Специфікація BLE протоколу (Honeywell HTRAM)

- **Service UUID**: `fc247940-6e08-11e4-80fc-0002a5d5c51b`
- **Write Characteristic**: `3d115840-6e0b-11e4-b24f-0002a5d5c51b`
- **Notify Characteristic**: `f833d6c0-6e0b-11e4-9136-0002a5d5c51b`

### Формат кадру:
`7B 41 00 <length> <cmd_u16_be> <body...> <crc16_be> 7D`
- `length`: довжина корисного навантаження (команда + тіло + 3 байти на CRC та завершальний `0x7D`).
- CRC-16: поліном `0x8005`, початкове значення `0x0000`, MSB-first.

### Ключові команди:
1. **Зміна режиму BLE**: `7B 41 00 0C 74 58 01 01 00 4E 08 7D` (відправляється після підключення).
2. **Запит телеметрії (CO2, T, H, батарея)**: `CMD 0x4044` -> відповідь `0x4144`.
3. **Статус зумера**: `CMD 0x2623` -> відповідь `0x2723`.
4. **Вимкнення / увімкнення зумера**: `CMD 0x2643` + `01 00 00 <00/01>`.
5. **Синхронізація часу**: `CMD 0x2035` + `01 <YY> <MM> <DD> <HH> <MM> <SS>`.
6. **Пороги та таймер екрана**: `CMD 0x4043` (читання) / `CMD 0x4044` (запис).
7. **Одиниця температури (°C/°F)**: `CMD 0x206E` (читання) / `CMD 0x2232` (запис).
