> **Автономний веб-застосунок для конфігурації та моніторингу датчика якості повітря Honeywell Transmission Risk Air Monitor (HTRAM-V1-W) через Web Bluetooth API.**

Працює повністю **локально у браузері** без сторонніх хмарних серверів, реєстрацій та плати за підписки.

## 🎯 Можливості та функції

1. **🔕 Керування зумером (Buzzer Mute)**:
   - Можливість увімкнути або вимкнути постійне набридливе пищання сигналу тривоги при перевищенні CO₂ в один клік — без випоювання динаміка з друкованої плати.
2. **📥 Зчитування архіву пам'яті приладу (Flash Log ~90 днів)**:
   - Прилад автономно зберігає заміри у вбудовану пам'ять SPI Flash (Winbond 25Q32). Веб-застосунок дозволяє вивантажити повний автономний архів за всі дні роботи по ланцюжку адрес (`0x2093` / `0x2193`), відобразити багатоденний таймлайн на графіку та зберегти в CSV для Excel.
3. **⏱ Синхронізація точного часу (Clock Sync)**:
   - Встановлення годинника приладу відповідно до системного часу смартфона чи комп'ютера (зокрема перед вивантаженням журналу).
4. **📊 Моніторинг показників у реальному часі**:
   - **Вуглекислий газ (CO₂)**: числове значення у ppm, динамічна шкала та кольорові стани відповідно до встановлених порогів.
   - **Кліматичний блок**: спарений моніторинг температури (°C / °F) та відносної вологості (%) із підказками діапазону комфорту.
   - **Акумулятор та живлення**: окрема картка з відсотком заряду, 4-сегментним графічним індикатором та виявленням підключення зарядного кабелю (⚡).
5. **📈 Інтерактивний графік та експорт у CSV**:
   - Живий інтерактивний графік концентрації CO₂ на HTML5 Canvas із пунктирними лініями порогів тривоги.
   - Міні-аналітика: діапазон дат архіву, мінімум, середній та максимум CO₂, загальна кількість зрізів.
   - Експорт архіву або поточної сесії у CSV з коректним кодуванням **UTF-8 з BOM** (без проблем відкривається в Microsoft Excel).
6. **⚙️ Налаштування апаратних параметрів**:
   - Налаштування порогів попередження та тривоги CO₂ (Low / High ppm).
   - Апаратний таймер підсвічування екрана: `0` (Завжди увімкнений / Always On) або `120` (Автовимкнення через 2 хвилини) відповідно до специфікації мікроконтролера GD32.
   - Перемикання одиниць температури на екрані приладу (°C / °F).
7. **🐱 Підтримка розробника**:
   - Вбудована банка Monobank для підтримки розробки українського відкритого софту.

## 🌐 Підтримувані платформи та браузери

Web Bluetooth API працює у захищеному середовищі (**HTTPS** або **localhost**):

| Платформа | Браузер | Статус | Примітки |
|---|---|---|---|
| **Android** | Chrome, Edge, Opera | ✅ Працює з коробки | Потрібен увімкнений Bluetooth та геолокація |
| **Windows / macOS** | Chrome, Edge | ✅ Працює з коробки | Bluetooth 4.0+ LE адаптер |
| **Linux (Ubuntu/Debian)** | Chrome, Chromium | ✅ Працює | Працює через системну службу `bluetoothd` (BlueZ) |
| **Linux / Win / Mac** | Brave Browser | ⚠️ Потрібно увімкнути флаг | Відкрийте `brave://flags/#enable-web-bluetooth` -> **Enabled** |
| **iOS (iPhone / iPad)** | Bluefy, WebBLE | ✅ Працює через сторонній браузер | Safari на iOS не підтримує Web Bluetooth |

## 📡 Специфікація BLE протоколу

- **Service UUID**: `fc247940-6e08-11e4-80fc-0002a5d5c51b`
- **Write Characteristic**: `3d115840-6e0b-11e4-b24f-0002a5d5c51b`
- **Notify Characteristic**: `f833d6c0-6e0b-11e4-9136-0002a5d5c51b`

### Формат кадру:
```
7B 41 00 <length> <cmd_be_u16> <body...> <crc16_be> 7D
```
- Преамбула: `0x7B 0x41 0x00`.
- CRC-16: поліном `0x8005`, `init=0x0000`, `MSB-first`.
- Завершальний байт: `0x7D`.

### Таблиця основних команд:
| Команда | Опкод запиту | Відповідь | Опис |
|---|---|---|---|
| Radio Mode | `0x7458` | — | Ініціалізація зв'язку у режимі BLE (`01 01 00`) |
| Heartbeat | `0x2401` | `0x2501` | Підтримка з'єднання (кожні 15 с) |
| Realtime Data | `0x4044` | `0x4144` | Опитування телеметрії (CO₂, T, H, батарея) |
| Get Sound | `0x2623` | `0x2723` | Зчитування поточного стану динаміка |
| Set Sound | `0x2643` | `0x2743` | Увімкнення / вимкнення зумера |
| Sync Time | `0x2242` | `0x2342` | Синхронізація годинника девайса |
| Get Settings | `0x4043` | `0x4143` | Зчитування порогів CO₂ та таймера екрана |
| Set Settings | `0x4243` | `0x4343` | Запис порогів CO₂ та таймера екрана |
| Set Temp Unit | `0x2232` | `0x2332` | Перемикання відображення °C/°F на LCD |
| Fetch Datalog | `0x2093` | `0x2193` | Посторінкове зчитування блоків архіву з SPI Flash (8 байт на запис: ts, co2, temp, hum) |

## 🙏 Подяки та першоджерела (Credits & Acknowledgments)

Особлива подяка автору проєкту [honeywell-htram-v1w-ble-monitor](https://github.com/noname122021/honeywell-htram-v1w-ble-monitor) (**noname122021**).

У його репозиторії було виконано фундаментальний реверс-інжиніринг оригінального мобільного застосунку Honeywell (`MicroRAECmdClass.smali`) та аналіз плати приладу, звідки ми почерпнули та використали для нашої чистої веб-імплементації:
1. **Протокол вивантаження автономного журналу Flash-пам'яті**: опкод команди опитування `0x2093` та відповіді `0x2193`, початкову адресу запиту `0xFFFFFFFF`, механізм ланцюжка адрес наступного блоку `next_addr` (до сигналу термінації `0xFFFFFFFF`) та структуру 8-байтових записів (4 байти UNIX Timestamp Big-Endian, 2 байти CO₂ ppm, 1 байт знакової температури, 1 байт вологості).
2. **Алгоритм та таблицю CRC-16**: розрахунок контрольної суми за поліномом `0x8005` (MSB-first) для валідації кадрів.
3. **Структуру команди синхронізації часу**: формат пакета `0x2242` (`01 YY MM DD HH MM SS`).
4. **Особливості GATT-сервісу**: UUID сервісу та характеристик запису/нотифікацій при роботі через Web Bluetooth API.

Також висловлюємо вдячність спільноті дослідників альтернативних прошивок датчиків якості повітря та розробникам інструментів Web Bluetooth.
