Ось як увімкнути Bluetooth залежно від вашої системи та браузера:

🦁 1. Якщо ви використовуєте Brave (Linux / Windows / macOS)

У Brave Web Bluetooth вимкнено за замовчуванням з міркувань приватності. Щоб увімкнути:

  1. Введіть в адресному рядку Brave: brave://flags/#enable-web-bluetooth
  2. Знайдіть прапорець Web Bluetooth (та за потреби Web Bluetooth new permissions backend).
  3. Переведіть його у стан Enabled.
  4. Натисніть кнопку Relaunch у правому нижньому кутку для перезапуску браузера.

🔒 2. Вимога безпечного середовища (HTTPS або localhost)

Специфікація Web Bluetooth працює виключно в захищеному контексті:

  • ✅ Працює з коробки: http://localhost:8080 або http://127.0.0.1:8080
  • ✅ Працює: будь-яке з'єднання через https://...
  • ❌ Блокується за замовчуванням: відкриття за локальною IP (наприклад, http://192.168.X.X:8080).
    Рішення для локальної мережі: введіть у браузері chrome://flags/#unsafely-treat-insecure-origin-as-secure (або brave://flags/...), додайте у поле повну адресу (наприклад, http://192.168.1.100:8080), перемкніть у Enabled та перезапустіть браузер.

🐧 3. Для користувачів Linux (BlueZ)

У системі Linux браузери Chromium звертаються до системної служби Bluetooth:

  • Перевірте, чи запущено демон: systemctl status bluetooth
  • Якщо пристрій не сканується, увімкніть експериментальний режим у /etc/bluetooth/main.conf:
    У секції [General] додайте Experimental = true та перезапустіть: sudo systemctl restart bluetooth

📱 4. Для пристроїв Apple iOS (iPhone / iPad)

Мобільний Safari на iOS апаратно не підтримує Web Bluetooth. Встановіть з App Store безкоштовний браузер з підтримкою Bluetooth — Bluefy або WebBLE, і відкрийте сторінку в ньому.
